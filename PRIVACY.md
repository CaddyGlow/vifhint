# Privacy Policy

**Last updated:** December 31, 2024

## Overview

Hint is a browser extension for keyboard-driven link navigation. This privacy policy explains how the extension handles user data.

## Data Collection

**Hint does not collect, store, or transmit any user data.**

Specifically, the extension:

- Does not collect personal information
- Does not collect browsing history
- Does not track user activity
- Does not use analytics or telemetry
- Does not communicate with external servers
- Does not store any data locally beyond Chrome's built-in extension storage for settings

## How the Extension Works

Hint operates entirely within your browser. When activated:

1. The extension scans the current page for clickable elements
2. Displays keyboard hint labels overlay on those elements
3. Removes the overlay after navigation or cancellation

All processing occurs locally in your browser. No data leaves your device.

## Permissions

The extension requires the following permissions:

- **activeTab**: To display hint labels on the current page when activated
- **scripting**: To inject the hint overlay into web pages

These permissions are used solely to provide the core functionality of keyboard-driven navigation.

## Third-Party Services

This extension does not use any third-party services, APIs, or analytics platforms.

## Changes to This Policy

Any updates to this privacy policy will be reflected in the extension's repository and the "Last updated" date above.

## Contact

If you have questions about this privacy policy, please open an issue in the project repository.
